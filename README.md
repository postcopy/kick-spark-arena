# S-FIGHT PRO

Plataforma profissional de treinamento gamificado para academias de Taekwondo.

## Modos de Jogo

- **Time Attack** - Treinamento de velocidade com cronômetro
- **Arcade** - Modo combate com HP e rounds
- **Reaction** - Treinamento de reflexo e tempo de reação

## Tecnologias

- React + TypeScript + Vite
- Tailwind CSS + shadcn/ui
- Electron (aplicativo desktop Windows)
- Web Serial API (sensores de impacto)
- Supabase (autenticação e dados)

## Build

```bash
# Desenvolvimento web
npm run dev

# Build do instalador Windows
npm run electron:build
```
